# Sistema de Turnos Odontológico

## Integración con MCP (Model Context Protocol)

Este repositorio incorpora soporte para servidores MCP en el entorno de trabajo:

- **Servidor Integrado:** `Postgres MCP Server`
- **Utilidad:** Permite la consulta e inspección estructurada en tiempo real del esquema relacional en PostgreSQL para validar tablas de turnos, agendas y profesionales durante los flujos OpenSpec.
